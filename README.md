# Workflow Course Assignment

This project is part of the Front-End Development Workflow course. The goal of the assignment is to configure tools that improve code quality and workflow efficiency.

## Setup Instructions

### 1. Install Dependencies:

Run the following comman to install
`bash`
npm install

### 2. Run linting:

`bash`
npm run lint

### 3. Format code:

`bash`
npm run format

### 4. Run tests:

`bash`
npm run test

## Tools Used

- ESLint - checks coding standards
- Prettier - formats code automatically
- Husky & Lint-Staged - runs lint/format before each commit
- Vitest - runs testes
